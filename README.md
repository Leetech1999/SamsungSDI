# SamsungSDI (React)

## 프로젝트 소개  
기존 삼성SDI PR 센터 웹페이지를 React 기반으로 재구현하며 컴포넌트화와 모던한 개발 방식을 적용했습니다.

## 주요 기능  
- 뉴스 카드 슬라이더 및 애니메이션 구현 (Swiper)  
- TailwindCSS 기반 반응형 스타일링  
- Intersection Observer API 활용 스크롤 애니메이션

## 사용 기술  
React, Swiper, TailwindCSS
